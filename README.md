### 🧩 Minha jornada em Quality Assurance

Durante minha formação na TripleTen, tive a oportunidade de colocar a mão na massa e aprender sobre diferentes etapas dos testes de software.

Algumas coisas que fazem parte do meu universo:

- Testes manuais, funcionais, exploratórios e regressivos.
- Testes de API com Postman.
- Automação de testes com Python, Selenium WebDriver e Pytest.
- Elaboração de casos de teste, checklists e cenários de teste.
- Classes de equivalência e análise de valor limite.
- Identificação, documentação e acompanhamento de bugs.
- Validação de respostas JSON e consultas SQL.
